Zomato restaurant data analysis using Python, Pandas, Matplotlib and SQL

# Zomato Data Analysis 📊

## Project Overview
This project performs exploratory data analysis on the Zomato restaurant dataset to uncover insights about ratings, pricing, and cuisines.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Top rated cuisines
- City-wise restaurant distribution
- Price vs Rating analysis

## How to Run
1. Clone the repository
2. Install dependencies
3. Run the Jupyter Notebook
